# Publish this portfolio on GitHub Pages

1. Create a GitHub repo named `<your-username>.github.io` (public). Your site will live at https://<your-username>.github.io
2. Upload everything in this folder: `index.html`, `README.md` and the `assets` folder (photo and CV PDF).
3. In the repo go to Settings > Pages, set Source to "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Wait 1-2 minutes, then open your link.

Tip: put a copy of README.md in a repo named exactly like your username to show it on your GitHub profile page.
